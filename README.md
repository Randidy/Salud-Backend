# SaludVital Backend - Microservicios

Ecosistema Spring Boot/Spring Cloud multi-módulo con puertos fijos:
- api-gateway 8001
- gestion-medicamentos-ws 8081
- medico-service-ws 8082
- auth-service-ws 8083
- paciente-service-ws 8086
- notificaciones-service 8089
- reportes-service-ws 8090
- cita-service-ws 8010
- eureka-server 8761
- config-server 8888

Detalles de arquitectura y migración en `docs/migracion-microservicios.md`.
